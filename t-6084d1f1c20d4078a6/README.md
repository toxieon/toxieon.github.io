# Test assets page (unlisted)

Test-only. Fake data, no network calls, nothing posts anywhere. Unlisted: `.nd-private` marker, noindex, no hub tile, not in sitemap or robots.

- `index.html`, `app.js`, `states.js`, `style.css`: the page. `states.js` holds every state table (also read by the node test).
- `vendor/`: three.js r169 (MIT, `LICENSE-three.txt`) with the GLTF loader, meshopt decoder (MIT) and skeleton utils, plus `flyby.js` (ball fly-past) and `kits.js` (player kit colours).
- `models/`: 17 ball GLBs + manifest, player v2.1 (23 clips), 7 racecourse GLBs. All original models; none are club or league assets.
- Goal, behind and sponsor-win effects are written fresh for this page (DOM, canvas and three.js); they reuse no other project's code.
- CSP: its own `<meta>`, generated by `node scripts/csp.cjs` (profile `testassets`). Blob and data sources are allowed for model textures only; nothing external.
- Run locally: serve the repo root with any static server and open this folder. `?fallback=1` forces the 2D scene.
