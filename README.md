# neilldata-site

Static GitHub Pages site for [www.neilldata.com](https://www.neilldata.com).

Node scripts at the repo root (`npm test`, `npm run hub:check`, `npm run icons:check`) use built-ins only. See [hub/README.md](hub/README.md) for the Suite hub.
