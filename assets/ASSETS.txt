 NEILL DATA SUITE — REUSABLE ASSETS
 A growing library of drop-in feature components shared across the apps
 (uploader, quote, planner, timesheet, swb, hub).
 Update this file whenever an asset is added, changed, or wired into an app.
 Last updated: 2026-07-29
========================================================================

HOW THIS RELATES TO /shared
  /shared  = low-level runtime modules the apps already depend on
             (nd-auth, nd-sheets, nd-queue, nd-cache, nd-ui, nd-core.css, …).
  /assets  = higher-level, self-contained FEATURE components you can lift
             into any app with a single <script> tag. This is the library
             we grow as we pull the "best of" each app into one place.

  Load an asset by adding, before your app script:
      <script src="../assets/here.js"></script>

 ASSETS PRESENT
------------------------------------------------------------------------

[1] here.js  —  "Here" one-tap geolocation → address
    Global:   NDHere
    Origin:   Quote (#use-location-btn)
    Needs:    navigator.geolocation + google.maps.Geocoder (host loads Maps)
    API:      NDHere.locate(opts) -> Promise<{address, lat, lng}>
              NDHere.fill(inputEl, opts)      (writes address into a field)
              NDHere.attachButton(btn, inputEl, opts)   (one-call wiring)
    Options:  region ("au"), highAccuracy, timeout, busyLabel, mapsKey,
              onResult(addr,coords), onError(err), notify(msg)
    Used by:  quote, uploader, planner, timesheet  (WIRED)
    Status:   WIRED into all four apps
    Notes:    Uses google.maps.Geocoder when the Maps JS library is loaded;
              falls back to REST geocoding via opts.mapsKey when it isn't
              (that's how Timesheet uses it). Errors surface via NDUI.toast
              when available, else alert().

[2] watermark.js  —  photo watermark info strip
    Global:   NDWatermark
    Origin:   Quote (drawWatermark)
    Needs:    Canvas 2D only (GPS lookup optional, uses geolocation)
    API:      NDWatermark.buildLines(data, toggles) -> string[]   (pure)
              NDWatermark.draw(ctx, w, h, {lines})                (sync)
              NDWatermark.stamp(source, {lines, maxDim, jpegQ}) -> dataURL
              NDWatermark.getGps(opts) -> Promise<"lat, lng"|null>
    Fields:   business, clientName, address, room, apartment, location,
              ref, datetime, initials, gps  (each individually toggleable;
              room/apt/location merge to one line; datetime + initials share
              a line, e.g. "27 Jul 2026 3:45 pm · BN")
    Toggles:  NDWatermark.DEFAULT_TOGGLES (clone + override per app)
    Used by:  uploader (baked on upload, per-field toggle panel + initials),
              quote (in-app camera capture)  — both WIRED
    Status:   WIRED. Uploader skips floor plans + HEIC; falls back to the
              original file on any error so an upload never fails.

[3] countdown-confirm.js  —  auto-confirming prompt with a depleting bar
    Global:   NDCountdownConfirm
    Origin:   Timesheet ("near" clock-on prompt)
    Needs:    nothing (self-contained; injects its own styles + DOM)
    API:      NDCountdownConfirm.open({ title, message, seconds=4,
                confirmLabel, secondaryLabel, accent,
                onConfirm, onSecondary, onCancel }) -> { close(fireCancel) }
    Behaviour: bar drains over `seconds`, then auto-fires onConfirm unless a
              button is tapped. Secondary = "change my mind" action; backdrop
              tap / Esc = cancel. "Assume yes, but give a moment to change."
    Used by:  Timesheet clock-on (pattern); available suite-wide
    Status:   BUILT

[4] exif-geo-detect.js  —  read a photo's GPS + capture time → address
    Global:   NDExifGeo
    Origin:   Uploader (EXIF auto-location)
    Needs:    exifr (window.exifr) + google.maps.Geocoder OR opts.mapsKey
    API:      NDExifGeo.readExif(file) -> { lat, lng, capturedAt }
              NDExifGeo.coordKey(lat, lng)                       (pure)
              NDExifGeo.reverseGeocode(lat, lng, { region, mapsKey })
              NDExifGeo.geocodeClusters(points, { cache, mapsKey })
                — one geocode per unique 5dp coordinate (40 photos = 1 call)
    Used by:  available (uploader's inline flow can migrate onto it)
    Status:   BUILT

[5] job-locator.js  —  match / create a job by location
    Global:   NDJobLocator
    Origin:   Timesheet (distanceMetres / nearestJob / resolveOrCreateJob)
    Needs:    nothing (pure)
    API:      NDJobLocator.distanceMetres(la1,ln1,la2,ln2)          (pure)
              NDJobLocator.nearest(jobs, lat, lng) -> { job, dist }
              NDJobLocator.match(jobs, lat, lng, { defaultRadius, nearMult })
                -> { tier: "here"|"near"|"none", job, dist }
              NDJobLocator.resolveOrCreate(jobs, spec, make)
    Used by:  available (timesheet can migrate; feeds log-book merge +
              uploader↔planner jobs)
    Status:   BUILT

[6] sync-fill.js  —  the "bubble fills up" sync indicator
    Global:   NDSyncFill
    Origin:   Timesheet (settings danger-fill panel)
    Needs:    nothing (self-contained; injects its own CSS)
    API:      NDSyncFill.apply(el, status)   — fill any element by status
              NDSyncFill.bind(el, queue)     — apply + follow queue.onStatus
    States:   synced (full green) · pending (low) · flushing/syncing (bobbing)
              · failed (near-empty red)
    Sibling of NDUI.syncTube: the tube is a small gauge; this fills the whole
    container (button / chip / text bubble). Wraps the element's content once
    so it stays legible above the water.
    Used by:  planner (sync buttons)
    Status:   BUILT

[7] address-autocomplete.js  —  Google Places autocomplete on a field
    Global:   NDAutocomplete
    Origin:   Quote + Uploader (inline Places autocomplete)
    Needs:    Maps JS API with libraries=places (host-loaded). Pairs w/ here.js
    API:      NDAutocomplete.attach(input, { country, types, fields, bounds,
                strictBounds, onSelect })  -> autocomplete | null
              NDAutocomplete.attachAll(selector, opts)
              NDAutocomplete.victoriaBounds()
    Used by:  available (quote/uploader can migrate onto it)
    Status:   BUILT

[8] camera-capture.js  —  in-app camera modal
    Global:   NDCamera
    Origin:   Quote (in-app camera)
    Needs:    getUserMedia (all modern browsers). Optional: watermark.js
    API:      NDCamera.open({ facingMode, maxDim, jpegQ, watermarkLines,
                infoText, closeAfterCapture, onCapture(dataUrl,{w,h}),
                onClose, onError }) -> { close }
              NDCamera.isSupported()
    Notes:    Full-screen preview, flip front/back, shutter downscales the
              frame and (optionally) stamps it via NDWatermark, returns a
              JPEG data URL. Self-contained (injects its own CSS + DOM).
    Used by:  available (quote can migrate; uploader can add capture)
    Status:   BUILT

[9] drive-image.js  —  authenticated Google Drive image loader
    Global:   NDDriveImage
    Origin:   the identical fetch-with-token pattern shipped in fit-off,
              planner and search (Drive thumbnail URLs 403 without cookies).
    Needs:    a valid OAuth access token (Drive scope); fetch/URL.
    API:      NDDriveImage.url(fileId, token) -> Promise<objectURL>
              NDDriveImage.hydrate({ getToken, root }) -> Promise
                  (swaps every img[data-fileid] under root using getToken())
              NDDriveImage.clearCache()
    Used by:  planner, search  (WIRED). fit-off keeps its own loadDriveMedia
              because it also rasterises PDF floor plans.
    Status:   WIRED (planner + search)
    Notes:    Per-fileId object-URL cache, so re-renders never refetch. Render
              a tile as <img data-fileid="DRIVE_ID">, then call hydrate() after
              paint. Replaced planner's 2-call dataURL path (1 call now).
