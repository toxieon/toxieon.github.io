# Neill Data (ND) suite logo: brand asset

This is the Neill Data brand mark, designed by Cinna and approved by Brandon. It is a **brand/logo asset only**. It is **not** the Hub's icon. The Hub uses the teal **Suite hub** icon (`assets/suite-icons/apps/hub.svg`, Hub 0.6.5).

| File | What it is |
|---|---|
| `nd-monogram.svg` | ND monogram, 512×512 viewBox. N amber `#E07B2A`, D off-white `#F4F6FA`, navy `#0F1420` rounded tile (rx 88). Outlined paths with no font or external references. |
| `nd-tile-180.png` | Stacked "Neill / Data" tile, opaque RGB at 180 px (Apple touch size). |
| `nd-tile-192.png`, `nd-tile-512.png` | The same stacked tile, RGBA, for general use. |
| `nd-maskable-192.png`, `nd-maskable-512.png` | Opaque RGB with the art inside the maskable safe zone, for Android/PWA `purpose: "maskable"`. |

Provenance: these files are byte-identical to `hub/favicon.svg` and `hub/icons/{icon-180,icon-192,icon-512,maskable-192,maskable-512}.png` from Hub 0.6.4 (commit 022d1f8, PR #37). They were the Hub's icons only briefly. Hub 0.6.5 (PR #38) went back to the Suite hub icon, so this folder is now the mark's canonical home. Catalogued in `assets/ASSETS.txt` [27] and the Assets showroom (`/1234567890/`, "Favicons & icons").

The source typeface of the outlined N/D glyphs wasn't recorded. Confirm it with Cinna before using the mark outside the suite.
