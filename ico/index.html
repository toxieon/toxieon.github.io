ICO Generator

Windows .ico with the program name and version on it (16, 32, 48 and 256 px), so Desktop folders show what's inside at a glance. Navy background by default, or transparent (text gets a subtle outline so it reads on any wallpaper).

Make an icon

Use the Python API instead (scripts / Ray & Husker)

The page above draws the icon in your browser. For automation, run the Python API or CLI from ico/ in the repo (see ico/README.md):

pip install -r ico/requirements.txt
uvicorn ico.server:app --host 127.0.0.1 --port 8765

curl -fOJ "http://127.0.0.1:8765/ico?name=TipBot&version=0.45.1"
curl -fOJ "http://127.0.0.1:8765/ico?name=TipBot&version=0.45.1&bg=transparent"
python -m ico.cli TipBot 0.45.1 -o TipBot.ico
python -m ico.cli TipBot 0.45.1 --bg transparent
Uses the name/version/colours above.

Applying the icon to a Windows folder is done on the PC, e.g. FolderIkon or seticon-cli (both MIT).
