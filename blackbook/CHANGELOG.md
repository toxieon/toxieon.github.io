# Black Book changelog

## 0.2.1 · 2026-11-21 · discord-signin · Sign in with Discord on the page itself. The button sends the owner to TipBot's /auth/login with return_to=https://www.neilldata.com/blackbook/ (or the same path on neilldata.com when the page was opened there). TipBot's callback returns a one-time #code= fragment; the page POSTs it once to /api/auth/exchange and stores the session token as nd_owner_token. The existing tipdash #t= (and #token=) handoff still works and is not sent to /exchange. #signup= is ignored and stripped. The paste-a-token prompt is gone. A 401 clears the stored token and shows the Discord button again.
## 0.1.2 · 2026-11-21 · honest-errors · Add and edit errors now say "Database unavailable" when the API returns 503 (or error db_busy, warming, or unavailable), instead of a generic "try again". A leftover unconfirmed answer says the horse could not be matched to a stored start, not "search again".
## 0.1.1 · 2026-11-19 · live-api-contract · Aligned to the live TipBot 0.97.1 contract. Add/edit/restore answers: added and restored are 200; ambiguous and unconfirmed are 200 with ok:false; duplicate and cap are 409; invalid and empty are 400 with field betPrice or priority; each shows its own message and none is treated as a crash. pending:true horses show a "Pending match" tag. Race list uses label when present. Silks come back from the one allowed host (cdn.prod.pricekinetics.com, added to the CSP img-src) with a monogram fallback on error. An empty race card or next start says "Not entered".
## 0.1.0 · 2026-11-19 · initial · Owner-only Black Book at /blackbook/, ported from the tipdash build onto the Neill Data site in Apex Midnight. Reads TipBot's /api/owner/blackbook* live with a Bearer token (nd_owner_token, nd_models_owner_token as fallback; tipdash #t= handoff stripped at load). Screens: list, upcoming runs, archived with restore, horse page with edit/remove, add by search or race card. Signed out shows only the token gate; 404 shows "Not the owner". Demo with fake data on localhost ?demo=1 only. noindex, robots.txt Disallow, no sitemap entry, CSP limited to the TipBot host. Dropped from tipdash: Discord sign-in redirect, rail/tabs, silks images, Geist/Instrument Sans font files (system fonts).
