## 0.6.1 · 2026-10-06 · hub-autodiscover · Tiles are auto-discovered: hub/build-apps.cjs builds apps.json from every top-level folder with an index.html (nd:* meta tags, optional app.json, hub/discover.json for exclusions and the pre-discovery tiles); a GitHub Action regenerates it on push to main and hub/build-apps.test.cjs fails if it's stale. Service worker hub-v5: apps.json and the hub HTML are network-first (cache only offline), so a new tile shows on the first open after a deploy (v4 served apps.json stale-while-revalidate, which hid the ICO Generator tile until a second load). The installed hub also re-reads the list when resumed (max once a minute) and when a new service worker takes over
